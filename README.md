# a0ng.com homepage

The homepage and projects page are a small vinext app. Edit the copy in
`app/page.tsx` and `app/projects/page.tsx`, and edit the visual styles in
`app/globals.css`.

## Concepts posts

The Concepts archive starts empty. Add a post object to `app/concepts/posts.ts`
with a unique `slug`, an ISO `publishedAt` date (`YYYY-MM-DD`), a short
`summary`, a brief `quote` excerpt (without quotation marks), and `paragraphs`
for the article body. Posts are ordered by date; the newest one automatically
replaces the homepage's clearly labeled placeholder preview and links to its
article at `/concepts/<slug>`.

## Cloudflare deployment

Connect this GitHub repository to Cloudflare Workers Builds. Create a Worker
named `a0ngdotcom`, use `main` as the production branch, set the build
command to `pnpm run build`, and the deploy command to `pnpm run deploy`.
Cloudflare installs dependencies from `pnpm-lock.yaml`. The deploy script uses
the Wrangler config generated by the build, which includes the Worker and its
static assets. Test the Worker preview before attaching `a0ng.com`.

For local verification, run `pnpm run build` and
`pnpm exec wrangler deploy --dry-run --config dist/server/wrangler.json`.
